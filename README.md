# CivicLens — Community Action Network

A polished, responsive front-end prototype for a civic issue reporting and accountability platform.

## Run it
1. Extract the ZIP file.
2. Open the `civiclens` folder.
3. Double-click `index.html` to open it in a browser.
4. For local development, use VS Code with the Live Server extension and choose **Open with Live Server**.

## Features included
- Responsive dashboard and community issue board.
- Search, filter and sort reports.
- Submit a report with category, location, severity, estimated people affected and optional photo evidence.
- Transparent demo priority estimate.
- Community support voting.
- Report details and progress timeline.
- Management demo mode to update report status.
- Community verification for resolved reports.
- Browser localStorage persistence and demo reset.

## Important prototype limitations
This is a front-end demo. Reports and votes are saved only in the current browser using `localStorage`; they are not sent to a public database and cannot be seen by other users or city authorities. The priority score is a transparent rule-based demonstration, **not a trained AI model** and not an official emergency risk assessment. A real public launch needs a secure backend/API, authentication, moderation, reliable geocoding/maps, data protection, and agreements with the relevant local authorities.
